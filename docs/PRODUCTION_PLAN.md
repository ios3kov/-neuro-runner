## 2. Asset Pipeline & Naming Conventions

### 2.1 Naming Convention
Формат: `CATEGORY_Type_Name_Variant_LOD`
*   `ENV_Chunk_Straight_01`
*   `OBS_Wall_Tall_A`
*   `UI_Icon_Magnet_Active`

### 2.2 Asset Checklist (Требования)

**3D Models (.glb)**
*   [ ] **Pivot Point (Строго):**
    *   *Chunks:* `(0,0,0)` в начале модуля по Z, центр по X.
    *   *Obstacles:* Центр основания объекта (для точного позиционирования в лайне).
    *   *Player:* Центр масс (для корректного вращения/наклона).
*   [ ] **Geometry:** Triangulated, удалены back-faces. Scale (1,1,1). 1 unit = 1 meter.
*   [ ] **Compression:** Draco (Level 7-10). **Важно:** Декодирование происходит *один раз* при загрузке приложения (Preload), во время игры используется клонирование (Instancing).
*   [ ] **UVs:**
    *   UV1: Атлас материалов.
    *   UV2: Lightmap (опционально, только для крупных статических объектов, если используется запеченный свет).

**Textures**
*   [ ] **Format:** KTX2 (BasisU) для High/Mid tier, PNG/WebP фоллбек для Low tier.
*   [ ] **Size:** Power of Two (POT). Max 2048x2048 для атласа.

## 3. Test Plan (QA Strategy)

### 3.1 Device Matrix

| Tier | Устройства | Цель | Особенности |
| :--- | :--- | :--- | :--- |
| **High** | iPhone 13+, S21+ | 60 FPS (Stable) | DPR 2.0, Full VFX, Shadows |
| **Mid** | iPhone 11, Galaxy A52 | 55-60 FPS | DPR 1.0-1.5, Reduced VFX |
| **Low** | iPhone 8, Redmi 9 | 30 FPS (Stable) | DPR 0.8-1.0, No VFX, Simple Materials |
| **Desktop** | Telegram Desktop (Win/Mac) | 60 FPS | Управление клавиатурой, Window resizing |
| **Tablet** | iPad Air/Pro | 60 FPS | Safe Areas, UI Scaling |

### 3.2 Performance Tests
1.  **Input Latency:**
    *   Visual response < 2 кадров (33ms при 60fps).
    *   Visual response < 1 кадра (33ms при 30fps).
2.  **Thermal Throttling:**
    *   Тест 15 мин на High settings.
    *   **Критерий:** Игра должна автоматически понижать качество (DPR, VFX) при перегреве/падении FPS, но не крашиться.
3.  **Memory:**
    *   Отсутствие утечек JS Heap при рестарте уровней.
    *   Корректный `dispose()` геометри и текстур при выходе в меню.

### 3.3 Gameplay & Input Integrity
1.  **Gesture Classifier:**
    *   *Phantom Misses:* Свайп вверх не должен распознаваться как диагональ.
    *   *Edge Guard:* Игнорирование свайпов в нижних 15% экрана (системные жесты iOS).
    *   *Buffer:* Свайп во время анимации срабатывает ровно 1 раз (queue size = 1).
2.  **Impossible Seeds (Automated):**
    *   **Nightly Seed-Fuzzer:** Бот прогоняет 10,000+ сидов за ночь.
    *   **Fail Condition:** Найден сид, где невозможно избежать смерти (нет валидного пути).
    *   **Output:** Лог "смертельных" чанков.

### 3.4 Network & Persistence
1.  **Offline Play:** Игра запускается из кеша. Локальный сейв работает.
2.  **Cloud Sync:**
    *   При появлении сети результаты отправляются.
    *   Конфликт версий: приоритет серверному прогрессу (или merge стратегии).
3.  **Ad Integration:**
    *   Награда (Revive/Coins) выдается ровно 1 раз.
    *   При сбое загрузки рекламы игра не зависает (Soft-lock prevention).

## 4. Acceptance Criteria v1.0 (Критерии Приемки)

Релиз блокируется, если не выполнен хотя бы один пункт.

### A. Stability
*   [ ] **Crash Rate:** < 0.5% сессий.
*   [ ] **FPS:** P95 > 45 FPS на Mid-Tier девайсах.

### B. User Experience
*   [ ] **Tutorial Funnel:** > 85% завершения туториала.
*   [ ] **Readability:** Препятствия различимы на 20% яркости экрана.

### C. Fairness & Integrity
*   [ ] **Ranked Validation:** 100% результатов в лидерборде имеют флаг `is_ranked=true`. Раны с помощью (Lag Compensation, Mercy) помечены как `unranked`.
*   [ ] **Hitboxes:** Визуальное касание всегда соответствует смерти. Нет "смерти от воздуха".

## 5. Tutorial Level Design: "Glass Corridor 01"

**Цель:** Обучить 4 жестам за 65-75 секунд.
**Концепция:** Конечный уровень. После финиша -> переход в Endless Mode.

### Глобальные настройки (Tutorial Only)
| Параметр | Значение |
| :--- | :--- |
| **baseSpeed** | 9.0 m/s |
| **maxSpeed** | 14.5 m/s |
| **Input Buffer** | 0.20 s |
| **Coyote Time** | 0.10 s |
| **Camera Roll** | 0° (Отключен для стабильности) |

### Сценарий (Beat Sheet)

**Beat 0: Старт (0-6 сек)**
*   Широкий коридор, разметка.
*   10 капсул валюты по центру.

**Beat 1: Свайпы (6-16 сек)**
*   **Задача:** Смена полосы.
*   **Препятствие:** Lane Block (Центр).
*   **UI:** Иконка "← →".
*   *Fail-safe:* Мягкое авто-подруливание, если игрок не реагирует.

**Beat 2: Прыжок (16-28 сек)**
*   **Задача:** Прыжок.
*   **Препятствие:** Low Beam (Центр).
*   **Телеграф:** 6 капсул дугой вверх.
*   **UI:** Иконка "↑".
*   *Fail-safe:* "Щит туториала" (урон игнорируется), повтор подсказки.

**Beat 3: Слайд (28-40 сек)**
*   **Задача:** Подкат.
*   **Препятствие:** High Gate (Центр).
*   **Телеграф:** 6 капсул по низу.
*   **UI:** Иконка "↓".

**Beat 4: Комбинация (40-55 сек)**
*   Последовательность: Lane Switch -> Jump -> Slide.
*   Расстояние между действиями: > 1.2 сек (без давления).

**Beat 5: Mag-Rails Event (55-68 сек)**
*   Визуальный "Вау-момент". Персонаж бежит по стене (рельсу).
*   Без сложных препятствий, только сбор монет.

**Beat 6: Финиш (68-75 сек)**
*   Выход в панораму города.
*   Экран: "TRAINING COMPLETE". Кнопка: "START RUN".
